> **MQPLUS** é uma plataforma educacional de alta performance desenvolvida para estudantes do Ensino Médio, vestibulandos e candidatos a Institutos Federais e Escolas Técnicas. O produto integra **Aprendizado Ativo (TRI)**, **Repetição Espaçada (SRS/Anki)**, **Inteligência Artificial Socrática (RAG)** e **Gestão de Saúde Mental** em uma experiência 360° unificada.

---

## 📌 Visão Geral do Produto

O **MQPLUS** resolve a fragmentação das ferramentas de estudo e o esgotamento emocional do vestibulando brasileiro. Combinando ciência pedagógica e tecnologia avançada, a plataforma atua como o **Co-piloto de Aprendizagem do Estudante**, oferecendo um caminho direto e personalizado até a aprovação.

```
+-----------------------------------------------------------------------------------+
|                               ECOSSISTEMA MQPLUS                                  |
+-----------------------------------------------------------------------------------+
|  [ Banco de Questões TRI ]  <--->  [ Tutor de IA Socrático 24/7 ]               |
|             |                                   |                                 |
|             v                                   v                                 |
|  [ Flashcards SRS (Anki) ]  <--->  [ Cronograma & Saúde Mental Integrados ]      |
+-----------------------------------------------------------------------------------+
```

---

## 🚀 Principais Diferenciais

- 🧠 **IA Tutor Socrático:** Monitor cognitivo 24/7 que guia o aluno com perguntas e orientações sem entregar o gabarito de primeira.
- 📊 **Engine de Simulados com TRI:** Cálculo preditivo da nota no ENEM baseado nos parâmetros oficiais de discriminação, dificuldade e acerto ao acaso.
- 🔄 **Algoritmo de Repetição Espaçada (SRS):** Sistema automatizado de flashcards baseado no modelo SM-2, que combate a curva de esquecimento.
- 💙 **Protocolo de Saúde Mental Integrado:** Triagem de ansiedade (GAD-7), diário de humor e pausas inteligentes para evitar o *burnout*.
- 🎯 **Foco em Segmentos Estratégicos:** Trilhas dedicadas para vestibulinhos de Institutos Federais (IFs), ETECs e Olimpíadas Científicas (OBMEP, OBF, OBQ).

## 🗺️ Roadmap de Produto (3 Anos)

```
2026 (Ano 1)                    2027 (Ano 2)                    2028 (Ano 3)
Q1   Q2   Q3   Q4             Q1   Q2   Q3   Q4             Q1   Q2   Q3   Q4
|----|----|----|----|         |----|----|----|----|         |----|----|----|----|
[=== MVP WEB ===]             [==== V3 B2B ====]             [==== V5 INT ====]
     [=== V2 MOBILE ===]           [==== V4 CONCURSOS ===]
```

- **MVP (Mês 1–4):** Lançamento Web Core (Questões, Simulados TRI, Flashcards SRS, IA Tutor).
- **V2 (Mês 5–8):** Apps Nativos Mobile (iOS/Android), Gamificação Avançada, Saúde Mental V1, Carreiras.
- **V3 (Mês 9–14):** B2B Escolas (Portal Coordenador/Professor), Módulo IFs/ETECs/Olimpíadas, Corretor de Redação.
- **V4 (Mês 15–22):** Fórum da Comunidade, Rachas Multiplayer 1v1, Trilha de Concursos Nível Médio.
- **V5 (Mês 23–36):** Previsão Preditiva de Aprovação e Expansão para América Latina.
